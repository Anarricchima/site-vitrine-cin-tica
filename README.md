# ☕ Site Nicácio Coffee

## 💡 Sobre o Projeto
Projeto desenvolvido como parte do desafio prático de **Desenvolvimento Web com HTML e CSS**, com o objetivo de estruturar páginas utilizando **HTML semântico** (`<header>`, `<nav>`, `<main>`, `<section>`), organizar elementos com **Flexbox** e aplicar estilização com **CSS puro**, sem utilização de frameworks[cite: 3]. O site simula a página de uma cafeteria fictícia, apresentando cardápio, serviços e um canal de atendimento e contato[cite: 3].

---

## 🛠️ Seções e Funcionalidades Implementadas
O projeto contempla os seguintes elementos estruturais e visuais exigidos:

- 🌟 **Hero Section**: Seção de destaque inicial com título, subtítulo e botão de chamada para ação (*CTA*)[cite: 3].
- 🏢 **Serviços / Sobre**: Seção informativa apresentando os serviços prestados (internet, jogos em rede, impressões e cafeteria).
- 📝 **Contato**: Formulário simples contendo campos para Nome, E-mail e Mensagem[cite: 3].
- 🎨 **Estilização com CSS Puro**: Layout estilizado inteiramente via folha de estilos personalizada.
- 📄 **Navegação**: Links estruturados para transição entre as páginas do site (Home, Serviços e Cardápio).
